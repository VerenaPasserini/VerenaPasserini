# Hi, I'm Verena Passerini 👋

**Bioinformatician** specialised in NGS data analysis for cancer research — from raw reads to biological insight.
I build reproducible pipelines and analyses across genomics, transcriptomics and epigenomics.

### 🔬 What I work on
- **NGS sequencing analysis** — QC, alignment, targeted, exome and whole-genome data
- **Variant calling** — somatic and germline SNVs/indels, Panel of Normals, annotation
- **Clonal evolution** — tumor subclonal reconstruction and phylogenies (e.g. diagnosis–relapse pairs)
- **RNA-seq** — differential expression, pathway and enrichment analysis
- **Spatial transcriptomics** — spatially resolved gene expression analysis
- **Methylome analysis** — DNA methylation profiling and differential methylation

### [AVANTseq](https://github.com/VerenaPasserini/AVANTseq) — Automated Variant Analysis for Next-gen Targeted Sequencing
A modular Snakemake workflow for somatic variant calling from paired-end targeted NGS data in cancer research:
custom Panel of Normals creation, GATK Mutect2 calling, Funcotator annotation, and FastQC/MultiQC reporting.
